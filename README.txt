Headline Generator Project

This project is my solution to a project that comprises part of the Full Stack Engineer learning path on Codecademy. The project was designed to strengthen skills in Git, GitHub, JavaScript, and command line.
The aim of the project was to build a message generator program with a randomized output. It required at least three variable pieces of data to ensure diverse possibilities for the output. I chose to create a project that produced absurdist headlines in a fictional newspaper dated within the 20th century, and given my interest in web design, I chose to display it as a web page, using my knowledge of HTML and CSS to make it more visually interesting.
